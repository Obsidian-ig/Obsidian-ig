# Project DNA
This is my new passion project that includes several "child" projects.   
Overall, this entire project is essentially my own virtual pet device similar to Starboy, but completely open-source, and customizable!
### DNA Animator
This is my vector-graphics animation software I have been working on for creating animations and rigs/characters for the device (Helix).   
This software lets anyone customize their devices however they want without having to edit hard-coded JSON values.

### Helix
This is the actual device that runs the virtual pet and assistant.   
It uses an ESP32-S3 device with a built-in AMOLED 466x466 Circular display for now. I might move onto a Linux SoC at some point, if I find that the esp32 itself is unable to fulfill my desires for this project.
